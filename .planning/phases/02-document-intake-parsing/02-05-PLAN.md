# Plan 02-05: Quality Scoring, Extraction Pipeline, and Route Integration

## Goal

Build the quality scoring module, the extraction pipeline orchestrator, and integrate both into the Route Handler. This replaces the transitional stub response from Plan 02-02 with real extraction and quality scoring. Upload records are updated with extracted text, quality score, and final status.

---

## Data Contract: Extractor Metadata → Quality Scorer

Plan 02-04 extractors produce format-specific metadata that Plan 02-05's `scoreQuality()` needs for scanned-PDF and fragmented-DOCX detection. This section makes the mapping explicit.

**Extractor outputs (from 02-04):**
- `extractPdfText()` → `PdfExtractionOutput { rawText, pageCount, warnings, textItemCount }`
- `extractDocxText()` → `DocxExtractionOutput { rawText, warnings, lineCount }`

**Quality scorer input (defined in this plan):**
```typescript
interface QualityInput {
  text: string;           // normalizedText from pipeline
  kind: 'pdf' | 'docx';  // DocumentKind from intake validation
  pageCount?: number;     // PDF only — from PdfExtractionOutput.pageCount
  textItemCount?: number; // PDF only — from PdfExtractionOutput.textItemCount
  lineCount?: number;     // DOCX only — from DocxExtractionOutput.lineCount
}
```

**Mapping in pipeline.ts:**
```
extractPdfText(bytes)  → { rawText, pageCount, textItemCount }
                             ↓           ↓            ↓
                        normalize()   passed      passed
                             ↓           ↓            ↓
                        scoreQuality({ text, kind:'pdf', pageCount, textItemCount })

extractDocxText(buf)   → { rawText, lineCount }
                             ↓          ↓
                        normalize()  passed
                             ↓          ↓
                        scoreQuality({ text, kind:'docx', lineCount })
```

    ```typescript
    import { extractPdfText } from "./extract-pdf";

    import { normalizeText } from "./normalize";
    import { scoreQuality } from "./quality";
    import type { QualityInput } from "./quality";
    import type { ExtractionResult, DocumentKind } from "./types";

    export async function runExtractionPipeline(
      fileBytes: Uint8Array,
      fileName: string,
      kind: DocumentKind,
      mime: string,
      sizeBytes: number
    ): Promise<ExtractionResult> {
      const startTime = Date.now();

      // 1. Extract raw text via format-specific adapter
      let rawText: string;
      let warnings: string[];
      let qualityInput: QualityInput;

      if (kind === "pdf") {
        const pdfResult = await extractPdfText(fileBytes);
        rawText = pdfResult.rawText;
        warnings = pdfResult.warnings;
        const normalizedText = normalizeText(rawText);
        // Explicit mapping: PDF metadata → quality scorer
        qualityInput = {
          text: normalizedText,
          kind: "pdf",
          pageCount: pdfResult.pageCount,
          textItemCount: pdfResult.textItemCount,
        };
      } else {
        const docxResult = await extractDocxText(
          Buffer.from(fileBytes)
        );
        rawText = docxResult.rawText;
        warnings = docxResult.warnings;
        const normalizedText = normalizeText(rawText);
        // Explicit mapping: DOCX metadata → quality scorer
        qualityInput = {
          text: normalizedText,
          kind: "docx",
          lineCount: docxResult.lineCount,
        };
      }

      // 2. Normalize text (NFC, CRLF, collapse spaces)
      const normalizedText = qualityInput.text;

      // 3. Score quality with explicit extractor metadata
      const quality = scoreQuality(qualityInput);

      // 4. Return ExtractionResult with processingTimeMs
      // ...
    }
    ```
