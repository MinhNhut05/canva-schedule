# Plan 02-03: Sidebar Navigation and Upload Page UI

## Goal

Build the app sidebar navigation and the complete upload page UI. The sidebar replaces the current header-only navigation with Vietnamese labels. The upload page provides drag-and-drop file selection, client-side validation, file preview, and server submission. This plan runs in parallel with Plan 02-02 (validation + route).

**D-12 compliance:** ALL visible UI text uses Vietnamese with full diacritics. No English labels in navigation, buttons, or status text.
