# Plan 02-02: File Validation Module and Route Handler

## Goal

Build the server-side file validation pipeline and authenticated upload Route Handler. Users can submit files via the upload form (Plan 02-03), which are validated for size, extension, and binary signature before being persisted as upload records. The Route Handler returns a transitional stub response that Plan 02-05 will replace with real extraction results.

**D-12 compliance:** ALL Vietnamese error messages use full diacritics.

       ```typescript
       import "server-only";

       export async function detectFileSignature(
         bytes: Uint8Array
       ): Promise<{ mime: string; ext: string } | undefined> {
         const { fileTypeFromBuffer } = await import("file-type");
         const result = await fileTypeFromBuffer(bytes);
         if (!result) return undefined;
         return { mime: result.mime, ext: result.ext };
       }
       ```

    2. Create `src/lib/documents/intake.ts` — file validation orchestration:
