# Plan 07-02: Persist Per-Upload One-day Canva Options and Review Warnings

## Objective

Introduce a saved 1-day generation preference in the review flow so the user can decide whether concise meal/menu lines should appear inside the itinerary. This choice must persist per upload, rehydrate when revisiting the review page, and surface a warning when merged content is likely too large for the template.

<action>
Add a durable place to store 1-day Canva generation preferences per upload. Keep it separate from the reviewed itinerary/menu facts.

The stored option set must at minimum support:
- `mergeMenuIntoItinerary: boolean`
- any small metadata needed to rehydrate warnings or defaults cleanly

Expose server actions/helpers to:
- load the saved option when opening `/review/[id]`
- update the option during review without forcing full regenerate
- ensure regenerate/retry uses the saved option value
</action>
<acceptance_criteria>
- `prisma/schema.prisma` (or equivalent durable model shape) stores the per-upload Canva option
- review actions can read and update the saved option independently of inline text edits
- regenerate/retry can access the saved option without requiring the user to re-toggle it
</acceptance_criteria>
</task>
