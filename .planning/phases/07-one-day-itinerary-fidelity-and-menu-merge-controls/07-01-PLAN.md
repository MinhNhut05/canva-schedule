# Plan 07-01: One-day Extraction Prompt and Conservative Condensation Rules

## Objective

Correct the 1-day wording contract at its source. The AI prompt and deterministic rules must stop over-shortening itinerary lines, preserve program-label fidelity, and support the user-approved condensation style for the canonical Day 1 sample. This plan should leave the codebase with a stable, testable rule set before any new review toggle or Canva payload logic is added.
