## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (gap-1, p-1) |
| sm | 8px | Compact element spacing, stepper connector (p-2, gap-2) |
| md | 16px | Default element spacing, Alert inner padding (p-4, gap-4) |
| lg | 24px | Section padding, stepper container (p-6) |
| xl | 32px | Layout gaps, stepper step circle diameter (p-8) |
| 2xl | 48px | Major section breaks (py-12) |
| 3xl | 64px | Page-level spacing (py-16) |

Exceptions:
- Stepper step circle: **32px diameter** (xl token — fixed for icon legibility at all breakpoints)
- Mobile stepper step circle: **28px diameter minimum** (compact mode, sm + md combined)
- Cooldown banner vertical padding: **12px** (between sm and md — 3px base × 4)
- Alert action button inside Alert: **mt-8px** (sm token) from `AlertDescription`

**Success (green, new, Phase 6) reserved for:**

## Interaction Contracts

### WorkflowStepper

**Step visual states:**

| State | Circle Style | Icon | Text Style | Clickable |
|-------|-------------|------|-----------|-----------|
| Completed | `bg-primary/20 text-primary` | `Check` (lucide) | `text-primary font-medium` | Yes — step 1 → `/upload`, steps 2–3 on review page → no navigate (same page) |
| Active | `bg-primary text-primary-foreground` | step number | `text-foreground font-semibold` | No |
| Error | `bg-destructive/20 text-destructive` | `AlertTriangle` (lucide) | `text-destructive font-medium` | No — shows Tooltip on hover |
| Future | `bg-muted text-muted-foreground` | step number | `text-muted-foreground` | No |

**Connector lines:**
- Before/at active step: `border-primary` (2px solid, 100% width)
- After active step: `border-border` (2px solid, muted)

**Responsive:**
- Desktop (`md:` and above): Step circle + text label below each step
- Mobile (below `md:`): Step circle + number/icon only, `hidden md:block` on labels

**Placement:** Inside `UploadForm` component (step 1 active) and `ReviewPage` component (step 2–5 based on upload status). NOT in shared `(app)/layout.tsx`.

**Step → status mapping (ReviewPage):**

| Upload/Artifact State | Active Step |
|----------------------|-------------|
| `/upload` page, default | Step 1 "Tải lên" |
| `aiStatus === PROCESSING` | Step 2 "Trích xuất" (active, Loader2 spinner in circle) |
| `aiStatus === FAILED` | Step 2 "Trích xuất" (error state, AlertTriangle) |
| `aiStatus === READY_FOR_REVIEW` | Step 3 "Duyệt" |
| `reviewStatus === APPROVED` | Step 4 "Tạo Canva" |
| `reviewStatus === APPROVED` + any artifact FAILED | Step 4 "Tạo Canva" (warning icon) |
| All artifacts SUCCEEDED | Step 5 "Hoàn thành" (checkmark) |

**Source:** CONTEXT.md D-01 through D-05, D-09, D-20 / RESEARCH.md §3.1

### Error Alert (inline, persistent)

| Property | Contract |
|----------|----------|
| Component | shadcn `Alert` with `variant="destructive"` |
| Persistence | Never auto-dismiss — user must explicitly act |
| Placement | Inline in the page section where failure occurred (below form/panel) |
| Structure | `AlertTitle` (error name) + `AlertDescription` (problem + hint) + `Button` (recovery action) |
| Previously used | `toast.error()` → replaced at all 3 failure points |
| Success toasts | `toast.success()` from sonner — KEEP as-is (D-06) |

**Source:** CONTEXT.md D-06/D-07/D-08

### Global Cooldown Banner

| Property | Contract |
|----------|----------|
| Trigger | DB `cooldownUntil > now()` — checked on page load (SSR) and after each Canva action |
| Position | Full-width banner above WorkflowStepper, top of review page |
| Style | `bg-amber-50 text-amber-800 border-b border-amber-200` |
| Countdown | `setInterval` every 30s, computes `remainingMinutes = Math.ceil((cooldownUntil - Date.now()) / 60000)` |
| Generate button | `disabled` + `cursor-not-allowed` during cooldown, re-enables when cooldown expires |
| Auto-clear | When `cooldownUntil < now()`, banner unmounts and button re-enables |
| Initial state | `initialCooldown: Date | null` passed from SSR page component via DB query |

**Source:** CONTEXT.md D-10/D-12/D-16 / RESEARCH.md §3.2/§3.5
