# Plan 06-01: Step Feedback, Error UX, Completion State

## Goal

Users see clear progress across the 5 workflow steps (upload, extract, review, generate, done), receive persistent inline error alerts with recovery actions at all 3 failure points, see a global cooldown banner when Canva rate-limits the team, and see a completion/partial-success banner with CTAs after generation finishes.

## must_haves (goal-backward verification)

- [ ] `src/lib/messages.ts` contains all Phase 6 Vietnamese text constants (stepper labels, error messages, cooldown, completion)
- [ ] `WorkflowStepper` component renders 5 steps with completed/active/error/future states
- [ ] Stepper is rendered inside UploadForm (step 1 active) and ReviewPage (step 2-5 based on status)
- [ ] Completed steps are clickable (step 1 navigates to /upload)
- [ ] Error steps show AlertTriangle icon with Tooltip
- [ ] Stepper is responsive: labels hidden below md breakpoint, step circles have aria-label
- [ ] UploadForm replaces `toast.error()` with persistent inline `Alert` component (destructive variant)
- [ ] ReviewPage Canva generation errors use persistent inline `Alert` instead of `toast.error()`
- [ ] `CompletionBanner` shows green success banner when all artifacts succeed with "Tao tour moi" and "Xem lich su" CTAs
- [ ] `CompletionBanner` shows partial success message when some artifacts fail
- [ ] `CooldownBanner` shows amber warning with countdown from global cooldown state
- [ ] `CooldownBanner` disables generate button during cooldown
- [ ] shadcn tooltip component is installed

**Props interface:**
```typescript
export type StepStatus = "completed" | "active" | "error" | "future";

export interface WorkflowStepperProps {
  /** 1-indexed active step (1 = Tai len, 2 = Trich xuat, ..., 5 = Hoan thanh) */
  activeStep: number;
  /** Step index (1-indexed) that has an error. Null if no error. */
  errorStep?: number | null;
  /** Whether to show a spinner icon in the active step circle */
  activeLoading?: boolean;
}
```

**Step rendering logic:**
For each step index 0-4 (mapping to STEPPER_LABELS[i]):
- If `index + 1 < activeStep` and `index + 1 !== errorStep` → status = `"completed"`
- If `index + 1 === errorStep` → status = `"error"`
- If `index + 1 === activeStep` and not error → status = `"active"`
- Otherwise → status = `"future"`

**Visual states (from UI-SPEC):**

| State | Circle classes | Icon |
|-------|---------------|------|
| completed | `bg-primary/20 text-primary` | Lucide `Check` (size 16) |
| active | `bg-primary text-primary-foreground` | step number (1-indexed) or `Loader2` with `animate-spin` if `activeLoading` |
| error | `bg-destructive/20 text-destructive` | Lucide `AlertTriangle` (size 16) |
| future | `bg-muted text-muted-foreground` | step number (1-indexed) |

**Step circle:** 32px diameter (`h-8 w-8`), `rounded-full`, `flex items-center justify-center`, `text-sm font-semibold`.

**Connector lines between steps:** Horizontal `div` with `h-0.5 flex-1`. If step before connector is completed or active: `bg-primary`. Otherwise: `bg-border`.

**Step label:** Below circle, `text-xs font-semibold mt-1.5`. Color matches circle state. On mobile: `hidden md:block`. Clickable completed steps and mobile step circles must have `aria-label={STEPPER_LABELS[i]}`.

**Clickable behavior (D-03):**
- Completed step 1 → `onClick` calls `router.push("/upload")` (uses `useRouter` from `next/navigation`)
- Completed steps 2-3 on review page → no navigation (same page, but visually clickable with `cursor-pointer`)
- Active, error, future steps → not clickable (`cursor-default`)

**Error tooltip (D-04):**
- When status is "error", wrap the step circle in `<TooltipProvider><Tooltip><TooltipTrigger>...<TooltipContent>{tooltipText}</TooltipContent></Tooltip></TooltipProvider>`
- Tooltip text: if errorStep === 2 → `STEPPER_TOOLTIPS.extraction`, if errorStep === 4 → `STEPPER_TOOLTIPS.canva`

**Layout:** `flex items-start justify-between w-full` container. Each step is a flex column with `items-center`. Connector lines are between step columns with `flex-1 self-center mt-4`.

**Responsive (D-05, D-20):** Container has `px-2 py-3 md:px-4 md:py-4`. Labels are `hidden md:block`.
